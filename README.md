# Inducción Vendedor Boutique — Cesantoni

Repositorio **privado** de la página de inducción.

## Cómo funciona

- **Página (este repo):** el formulario que usas en las PCs autorizadas.
- **Google Sheets (pestaña Avances):** base compartida. Ahí se guardan en curso y completados para seguirlos varios días y en distintos equipos.
- **Google Sheets (pestaña Registros):** histórico para KPIs / Excel. Se llena al pulsar Enviar.

Código de acceso de la página: `CESANTONI2026`

## Archivos

- `induccion-vendedor-boutique.html` — página
- `apps-script-induccion.gs` — script de Google (pegar en Apps Script y republicar)

## Equipos autorizados

1. Descarga el HTML de este repo.
2. Ábrelo en el navegador.
3. Escribe el código de acceso.
4. Verás la misma lista de colaboradores (viene de la hoja Avances).
